# 企鹅滑冰回家 · 游戏设定 v0.1

状态：第一阶段设定。英文名称 **Penguin Home Journey**，采用用户最新提供的封面标题。所有游戏内文案为英文。

## 核心体验

小企鹅迷失在冰面上，玩家规划滑动方向，借冰岩停下并转向，回到有家人等待的雪屋。挑战来自路线推理，没有限时压力，不依赖快速反应。

## 基础规则

| 项目 | 规则 |
| --- | --- |
| 地图 | 俯视、正交格子地图；视觉上的立体效果不改变格子关系 |
| 方向 | 上、下、左、右；键盘方向键和屏幕按钮对应相同指令 |
| 移动 | 一次有效方向输入触发连续直线滑动，途中不接受转向指令 |
| 停下 | 下一格为冰岩时，停在冰岩前一格 |
| 无效操作 | 相邻格就是冰岩时不移动、不计步 |
| 失败 | 进入海水格或滑出地图边缘；边缘不是墙，不自动刹车 |
| 通关 | 到达终点格立即停下并通关，即使该方向后续还有空地 |
| 路线检查 | 按顺序检查经过的每一格，不可穿过障碍或跳过海水 |
| 计步 | 每次有效滑动计一步，包括最后导致落水的滑动；滑过格数不影响计步 |
| 重试 | 恢复本关初始地图和角色位置，步数清零，可无限重试 |
| 连续输入 | 滑动中忽略新方向，不缓存为停止后的自动滑动；一次按下只触发一次指令 |
| 失败或通关后 | 停止接受移动输入，显示对应操作入口 |

## 第一版内容

- 5 个固定关卡；地图尺寸可按关卡调整，6×5 美术预览只作布局参考。
- 关卡递进目标：基础滑动与停下 → 借冰岩转向 → 海水与边缘 → 多次转向 → 综合路线。
- 只用固定冰岩、普通冰面、海水和终点；暂不包含钥匙、易碎冰、随机地图、排行榜和付费内容。
- 首页：使用用户封面，Start 进入第一关。
- 游戏页：游戏标题、Level、Moves、重试按钮、四方向按钮、简短提示。
- 失败：简短反馈和 Retry；通关：成功反馈和 Next；最后一关：完成提示和 Play Again / Home。
- 音乐和音效未提供，首个可运行版本不依赖音频。

## 验收要求（待实现后执行）

1. 所有关卡有独立记录的合法解；按同一规则逐步回放确认可通关。
2. 无效操作不计步；一段滑动只计一步；失败、重开与通关状态互不串扰。
3. 能检测途中海水和终点；不能只检查最终停靠位置。
4. 键盘和按钮一致；按住方向键不自动连滑；滑动时反复输入不改变当前方向。
5. 重试清除运动和输入残留；开始按钮点击不穿透成游戏操作。
6. 角色、障碍和终点各自的占格清楚，不遮住相邻格的关键内容。
7. XBuilder 实际编译、预览、导入和发布分别记录验证结果；本地逻辑测试不能替代平台试玩。
