# 试玩与验证记录

## v0.1 / fix1

- 用户导入后发现舞台数组 Board 与精灵类 Board 同名，已改为 LevelCells。
- 修复后用户明确反馈“可以正常运行”。这是用户平台运行反馈，不作为逐项边界验收证据。

## v0.2：独立素材与音频

新增：独立开始按钮及 6% 悬停放大、每格独立素材、独立操作按钮与结果组件、7 个声音、声音开关，以及中文平台描述和操作说明。

本地验证：

- 完整规则函数测试：各可站立格子的四方向与不同帧时间、无效操作、滑动锁定、终局和重试。
- 最短解仍为 Up → Right → Up → Right → Up，共 5 步。
- 舞台字段与精灵类不重名，按钮资源与脚本分离。
- 图片尺寸、声音 WAV 头和采样数、资源路径、精灵顺序与 ZIP 内容一致性。

平台待验收：

1. 首页只有一个 Start，悬停略微放大，移开恢复；点击进入关卡。
2. 按五步路线通关，步数为 5，播放回家声音。
3. 起点向左滑出边缘；重试后上、右、上、左、下滑入水洞，两种结果音效不同。
4. 重试、返回首页、连续切换声音开关，确认没有音乐重叠。
5. 移动独立按钮后仍能点击，检查透明边缘、画面布局和音量。

本轮不自动操作浏览器，不发布。真实引擎中新增声音和按钮行为需用户导入新版确认。

## v0.2.2：背景音乐调整

首页与关卡循环音乐替换为 MintoDog 的 CC0 无歌词解谜音乐。首页采用较慢、轻松的标题曲；关卡采用节奏稍快但不喧闹的解谜曲。移动、失败、通关和点击等短音效保持不变。

## v0.3：五关旅程

新增第 2 至第 5 关。每一关使用独立的冰面、水洞、冰岩和雪屋精灵；通过前四关后显示 Next Level，第五关完成后显示 Play Again 并回到首页。

| 关卡 | 最短路线 | 最少步数 |
|---|---|---:|
| 1 | Up → Right → Up → Right → Up | 5 |
| 2 | Right → Up → Left | 3 |
| 3 | Down → Right → Up → Left | 4 |
| 4 | Up → Right → Up → Left → Up | 5 |
| 5 | Right → Down → Right → Up → Right → Up | 6 |

本地测试遍历五张地图所有冰面格和四方向，以多种帧时间推进；同时验证每张地图的给定路线、最短路线、下一关、第五关收束、滑动锁定、音频切换和独立按钮范围。平台待验收：连续通关五关，确认 Level 标签、Next Level、第五关的完成画面和声音均正确。

## v0.3.1：界面与音乐调整

- 第一关恢复为 v0.2 的五步冰面路线。
- 所有结果页面的 Home 固定在左侧；黄色的 Retry、Next Level 或 Play Again 固定在右侧。
- Moves 数字放在标题正下方居中；重试图标改为不重叠的回转箭头。
- 首页音乐改为轻快的冬日钢琴/木管循环，关卡音乐改为柔和的冬日解谜循环；运行音量进一步降低。

平台待验收：检查三类结果页面的左右按钮顺序、Moves 对齐、重试图标和新版音乐听感。

## v0.2.1：正式环境指针兼容修复

v0.2 导入时报 mouseHitItem 未定义，影响舞台和 11 个按钮脚本。已移除该接口，改用正式站此前可用的 mouseX / mouseY、精灵 xpos / ypos / size 计算按钮矩形范围。按钮仍独立，移动按钮或调整大小后点击范围随之更新，悬停放大 6% 保留。隐藏声音按钮不接收点击。

新增位置移动、缩放和范围外点击的几何测试，以及打包时禁用该接口的检查。此次未自动操作浏览器，平台编译和悬停需导入 v0.2.1 确认。

- 重来图标缩小，使其与 Home 图标的视觉重量一致。

## v0.3.3：Moves 间距修正

- 下移 Moves 数字，避免与标题重叠，并保留在面板内部。
